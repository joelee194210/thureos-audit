# public/ayuda

Las imágenes de esta carpeta son las capturas que acompañan cada ficha del
Centro de Ayuda (`/ayuda/<slug>`).

`monitores.png` y `reglas.png` son capturas reales (1440×900, tomadas a mano
para la tarea 1) de `/monitors` y `/rules` respectivamente. Las once
restantes (`dashboard.png`, `banderas-rojas.png`, `cargas.png`,
`screening.png`, `dashboards.png`, `analista-ia.png`, `mcc.png`,
`paises.png`, `usuarios.png`, `bitacora-de-acceso.png`,
`configuracion.png`) son marcadores de 1×1 gris claro (`#e5e5e5`, no negro
opaco) agregados en la tarea 2. Todas se toman/reemplazan con
`capturar-ayuda.ts` (tarea 4 del plan), que además puede volver a generar
las dos primeras si la pantalla cambia.
