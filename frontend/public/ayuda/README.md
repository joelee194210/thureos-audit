# public/ayuda

Las imágenes de esta carpeta son las capturas que acompañan cada ficha del
Centro de Ayuda (`/ayuda/<slug>`).

Las que hay ahora (`monitores.png`, `reglas.png`) son **marcadores de
posición de 1×1 píxel**, provisorias. Se regeneran con `capturar-ayuda.ts`
(tarea 4 del plan), que reemplaza cada una por una captura real de la
pantalla correspondiente.
