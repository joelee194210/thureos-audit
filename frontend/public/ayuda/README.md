# public/ayuda

Las imágenes de esta carpeta son las capturas que acompañan cada ficha del
Centro de Ayuda (`/ayuda/<slug>`).

`monitores.png` y `reglas.png` son capturas reales (1440×900, tomadas a mano
para la tarea 1) de `/monitors` y `/rules` respectivamente. Las trece
restantes se toman con `capturar-ayuda.ts` (tarea 4 del plan), que además
puede volver a generar estas dos si la pantalla cambia.
